NAUTICAL INSPECTION & SURVEY — WEBSITE PACKAGE

Files:
 index.html    Main responsive single-page website
 styles.css    Website styling
 script.js     Service cards, mobile menu and email enquiry form
 assets/       Original logos supplied by the client

Preview:
 Open index.html in a browser. Internet access is helpful for Google Fonts, but the site uses fallback fonts offline.

Publishing:
 Upload all files and the assets folder to the public_html folder for www.nisbd.net (or deploy the folder to a static hosting service). Ensure DNS and hosting are configured separately.

Important:
 The enquiry form opens a pre-filled email using the visitor's email client. It does NOT submit to a server, store data or send automatically.
